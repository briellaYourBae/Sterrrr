# Ruang Cerita Ester

Website pribadi Ester, mahasiswi Sistem Informasi di Universitas AMIKOM Yogyakarta.

## Cara mengunduh repository ke laptop

Repository ini bisa diunduh sebagai file ZIP tanpa memasang aplikasi tambahan, atau disalin menggunakan Git.

### Cara 1: Unduh sebagai ZIP

1. Buka halaman repository: [github.com/briellaYourBae/Sterrrr](https://github.com/briellaYourBae/Sterrrr).
2. Klik tombol **Code**.
3. Pilih **Download ZIP**.
4. Setelah selesai, buka folder **Downloads** di laptop.
5. Klik kanan file `Sterrrr` yang berformat `.zip`, lalu pilih **Extract All...** (Windows) atau **Extract**.
6. Pilih lokasi penyimpanan dan buka folder hasil ekstraksi.

### Cara 2: Clone dengan Git

Jika Git sudah terpasang, buka PowerShell atau Terminal, lalu jalankan:

```bash
git clone https://github.com/briellaYourBae/Sterrrr.git
```

Perintah tersebut membuat folder `Sterrrr` di lokasi terminal saat ini. Untuk masuk ke foldernya:

```bash
cd Sterrrr
```

### Membuka website

1. Buka folder repository yang sudah diunduh atau di-clone.
2. Buka file `index.html` di browser untuk melihat halaman beranda.
3. Gunakan menu navigasi untuk membuka halaman lainnya.

Untuk mengedit website, buka folder repository menggunakan editor seperti Visual Studio Code. File halaman menggunakan HTML, sementara `styles.css` mengatur tampilannya.

## Isi repository

- `index.html` — halaman beranda.
- `aktifitas.html` — halaman aktivitas.
- `pendidikan.html` — halaman pendidikan.
- `jadwal kuliah.html` — halaman jadwal kuliah.
- `styles.css` — gaya dan tata letak seluruh halaman.
